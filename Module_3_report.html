Results & Analysis

The first part of the module shows how to draw the Sierpiński triangle using the methods we're familiar with, namely loops and turtle graphics. We define a simple function that draws an equilateral triangle, and then, like with the Koch snowflake and the Dragon curve, we use a recursion to draw the fractal. Here follows the code and the result. 


	# import the turtle setup
	!wget -O turtle_setup.py 'https://raw.githubusercontent.com/williamedwardhahn/fractal25/refs/heads/main/turtle_setup.py'
from turtle_setup import * 
	# Define the function to draw an equilateral triangle
def draw_triangle(length):
    for _ in range(3):
        forward(length)
        left(120)

	#Using recursion to define the fractal function
	def sierpinski_triangle(length, order):
    if order == 0:
        draw_triangle(length)
    else:
        sierpinski_triangle(length / 2, order - 1)
        forward(length / 2)
        sierpinski_triangle(length / 2, order - 1)
        backward(length / 2)
        left(60)
        forward(length / 2)
        right(60)
        sierpinski_triangle(length / 2, order - 1)
        left(60)
        backward(length / 2)
        right(60)

	initializeTurtle(initial_window_size=(1000, 2300), mode='auto')
showturtle()

# Draw the Sierpinski triangle
for order in range(0,5): # I changed this part so we can see each step in the process
  length = 400
  sierpinski_triangle(length, order)
  penup()
  jump(300,500+(order+1)*400)
  pendown()

show()

The next part of the module sets up Cellular Automaton with "rules" as inputs that produce many intricate and complex shapes. The first step is to import the libraries and then set up a function that will plot our image. We can think of it as a cartesian plane, but we hide the axis for visualisation purposes. 


	import numpy as np #importing the NumPy library
import matplotlib.pyplot as plt #importaing the MatPlot library

def plot(x):
    fig, ax = plt.subplots()  #creates the plane and the axes
    im = ax.imshow(x, cmap = 'gray') #set colorscheme to grayscale
    ax.axis('off') #hide the axes
    fig.set_size_inches(10, 10) # set image size
    plt.show() #show plot

Now we set up the starting state of the CA (Cellular Automaton), which is a black image with a single flipped pixel in the top middle. The code is pretty straightforwards. 


	C = np.zeros((100,100)).astype(int) # creates a 100x100 array with 0s
