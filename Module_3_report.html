Results & Analysis

The first part of the module shows how to draw the Sierpiński triangle using the methods we're familiar with, namely loops and turtle graphics. We define a simple function that draws an equilateral triangle, and then, like with the Koch snowflake and the Dragon curve, we use a recursion to draw the fractal. Here follows the code and the result. 


	# import the turtle setup
	!wget -O turtle_setup.py 'https://raw.githubusercontent.com/williamedwardhahn/fractal25/refs/heads/main/turtle_setup.py'
from turtle_setup import * 
	# Define the function to draw an equilateral triangle
def draw_triangle(length):
    for _ in range(3):
        forward(length)
        left(120)

	#Using recursion to define the fractal function
	def sierpinski_triangle(length, order):
    if order == 0:
        draw_triangle(length)
    else:
        sierpinski_triangle(length / 2, order - 1)
        forward(length / 2)
        sierpinski_triangle(length / 2, order - 1)
        backward(length / 2)
        left(60)
        forward(length / 2)
        right(60)
        sierpinski_triangle(length / 2, order - 1)
        left(60)
        backward(length / 2)
        right(60)

	initializeTurtle(initial_window_size=(1000, 2300), mode='auto')
showturtle()

# Set up the turtle
jump(300, 500)
face(90)
color('green')

# Draw the Sierpinski triangle
for order in range(0,5): # I changed this part so we can see each step in the process
  length = 400
  sierpinski_triangle(length, order)
  penup()
  jump(300,500+(order+1)*400)
  pendown()

show()
