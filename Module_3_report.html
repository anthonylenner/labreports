	def sierpinski_triangle(length, order):
    if order == 0:
        draw_triangle(length)
    else:
        sierpinski_triangle(length / 2, order - 1)
        forward(length / 2)
        sierpinski_triangle(length / 2, order - 1)
        backward(length / 2)
        left(60)
        forward(length / 2)
        right(60)
        sierpinski_triangle(length / 2, order - 1)
        left(60)

Next, we set up the rule that is going to define what the CA does. In this case, our rule is a function $\text{rule}: \{0,1\}^3 \to \{0,1\}$, that takes the state (0 or 1) of other cells to determine the new state of the cell being acted upon. What really varies here are the values that the function takes. We use take a number 0-255 and convert it to binary, with leading zeros so the number has 8 digits, and then take each degit of the binary number and associate it with an element from $\{0,1\}^3$ in the following way: 


	num = 90
	print(f'{num:08b}') # this converts num to binary with a total of 8 digits, 90 gets converted to 01011010, as we can see in the list below.

	rule = np.zeros((2,2,2)) #creates a three dimensional array with zeros

	rule[0,0,0] = 0
	rule[0,0,1] = 1
	rule[0,1,0] = 0
	rule[0,1,1] = 1
	rule[1,0,0] = 1
	rule[1,0,1] = 0
	rule[1,1,0] = 1
	rule[1,1,1] = 0

The last step is to create the CA function that will take an array as input and use the rule to change the array. 


	def CA(X):

    for i in range(1,X.shape[0]-1): #row
        for j in range(1,X.shape[1]-1): #col

            N  = X[i-1,j]
            NW = X[i-1,j-1]
            NE = X[i-1,j+1]

            X[i,j] = rule[NW,N,NE] # updates the value of the cell based of the value of the cell above it and the upper diagonal adjacent cells
    return X

There is also another CA function that the module presents, which is also interesting. It also uses the three upper adjacent cells to update the selected cell. But it "reads" them like a three digit binary number. to if three cells above are 010, the function converts the binary to decimal, $4(0)+2(1)+1(0)=2$. Then it divides the selected rule number by two to second power ( in this case) and takes the modulo 2. What is nice about this is that since we have a modulo 2, any integer can be a rule.
