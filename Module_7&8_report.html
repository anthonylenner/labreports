Introduction

In these two modules we learned how to code and visualise with intricate detail the Mandelbrot and Julia sets. The Mandelbrot set consists of complex numbers $c$ such that sequence $0, f(0), f(f(0)), f(f(f(0))), \dots$ where $f(z)=z^2 +c$ stays bounded. For a fixed complex number $c$, the Julia set represents the starting values $z$ such that $z, f(z), f(f(z)), f(f(f(z))), \dots$ stays bounded.

Results & Analysis

For the Mandelbrot set, we first create the mandelbrot_set function, which takes a complex number $c$ and returns the number $n$ of iterations it took for the absolute value of an iteration to be larger than or equal to 2, under a max_iter limit number of iterations. Then we create our coordinate system with np.linspace and an empty array two-dimensional n3 that we fill each point with the number n returned by the mandelbrot_set function when applied to the complex number associated with that point. Then the next step is just plotting like we have been doing with matplot. The result is a complex plane with a gradient based on how many iterations it took for a certain point to blow up to infinity. 


	import numpy as np
import matplotlib.pyplot as plt
from numba import jit

# JIT-optimized mandelbrot function
@jit(nopython=True)
def mandelbrot(c, max_iter):
    z = 0
    n = 0
    while abs(z) <= 2 and n < max_iter:
        z = z*z + c
        n += 1
    return n

# JIT-optimized mandelbrot set generator
@jit(nopython=True)
def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            n3[i, j] = mandelbrot(r1[i] + 1j * r2[j], max_iter)

    return n3

# Parameters for the plot
xmin, xmax, ymin, ymax = -2.0, 1.0, -1.5, 1.5
width, height = 800, 800
max_iter = 100

# Generate the Mandelbrot Set
n3 = mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter)
# Parameters for the initial zoom level
xmin, xmax, ymin, ymax = -0.75, -0.74, 0.1, 0.11  # Zoom into this specific area
width, height = 800, 800  # Resolution of the image
max_iter = 1000  # Number of iterations

# Generate the Mandelbrot Set with zoom
n3 = mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter)

# Plotting the zoomed Mandelbrot Set
plt.figure(figsize=(10, 10))
plt.imshow(n3.T, extent=[xmin, xmax, ymin, ymax], cmap='inferno')
plt.colorbar()
plt.title("Mandelbrot Set - Zoomed In")
plt.show()

The code for Julia sets is practically identical, but instead fo fixing $z=0$ and varying $c$ like in the Mandelbrot set, we instead fix a $c \in \mathbb{C}$ and vary the starting $z$s. 


	import numpy as np
import matplotlib.pyplot as plt
from numba import jit

# JIT-optimized function to generate the Julia Set
@jit(nopython=True)
def julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            z = r1[i] + 1j * r2[j]
            n = 0
            while abs(z) <= 2 and n < max_iter:
                z = z*z + c
                n += 1
            n3[i, j] = n

    return n3

# Parameters for the plot
xmin, xmax, ymin, ymax = -1.5, 1.5, -1.5, 1.5
width, height = 800, 800  # Image resolution
max_iter = 256  # Number of iterations for accuracy

# Choose a value for the complex constant c
c = complex(-0.8, 0.156)

# Generate the Julia Set
n3 = julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter)

# Plotting the Julia Set
plt.figure(figsize=(10, 10))
plt.imshow(n3.T, extent=[xmin, xmax, ymin, ymax], cmap='hot', interpolation='bilinear')
plt.colorbar()
plt.title(f"Julia Set for c = {c}")
plt.show()
