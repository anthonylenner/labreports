Introduction

In these two modules we learned how to code and visualise with intricate detail the Mandelbrot and Julia sets. The Mandelbrot set consists of complex numbers $c$ such that sequence $0, f(0), f(f(0)), f(f(f(0))), \dots$ where $f(z)=z^2 +c$ stays bounded. For a fixed complex number $c$, the Julia set represents the starting values $z$ such that $z, f(z), f(f(z)), f(f(f(z))), \dots$ stays bounded
