Introduction

In this short module, we learned how to code and display iterations of the Cantor set, a very curious and important set in mathematical analysis.

Results & Analysis

The construction of the Cantor set is very simple. We start with the segment [1,0]. Then we remove the open middle third (1/3,2/3) and remain with [0,1/3] and [2/3,1]. We do the same to these two segments and repeat the process infinitely. the Cantor set is the set of elements present in all these iterations. It is an example of very interesting properties, such as closedness, perfectness and uncountability. One can also alter the size of the removed intervals without affecting these properties. 


	# Import libraries for math and plotting
import numpy as np
import matplotlib.pyplot as plt

# Set initial parameters
x_start = 0       # Starting x-coordinate of the first bar
x_end = 3         # Ending x-coordinate of the first bar
y_position = 0    # Starting y-coordinate (height of the first bar)
bar_height = 5    # Height of each bar
spacing = 10      # Space between bars (distance downwards)
depth = 6         # Number of levels to draw
r = 3             # How much is removed from the middle

# Define a function to create the Cantor Set pattern
def cantor_set(x_start, x_end, y_position, r, depth):
    if depth == 0:
        return []

    # Left and right segments for the current bar
    left_segment = [[x_start, x_start + (x_end - x_start) / r, y_position]]
    right_segment = [[x_end - (x_end - x_start) / r, x_end, y_position]]

    # Recursively generate segments for the next levels
    # Pass 'r' and 'depth - 1' in the recursive calls
    left_recursive = cantor_set(x_start, x_start + (x_end - x_start) / r, y_position - spacing, r, depth - 1)  
    right_recursive = cantor_set(x_end - (x_end - x_start) / r, x_end, y_position - spacing, r, depth - 1)

    # Combine the current segments with the results from recursive calls
    return left_segment + right_segment + left_recursive + right_recursive

# Generate Cantor Set segments data
segments = np.array(cantor_set(x_start, x_end, y_position, r, depth))  # Convert to an array for easy plotting

# Plot the Cantor Set
plt.figure(figsize=(25, 25))

# Draw each segment as a black bar
for x_start, x_end, y in segments:
    plt.fill_between([x_start, x_end], [y] * 2, [y - bar_height] * 2, color="black")

# Hide the axes for a clean look
plt.axis('off')
plt.show()
